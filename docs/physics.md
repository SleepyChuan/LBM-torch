# 物理与数值规格

## 单位

全部用格子单位：`dx = dt = 1`，格子声速 `cs^2 = 1/3`，`cs = 1/sqrt(3)`。

松弛时间和运动粘度：

```
tau = nu / cs^2 + 0.5 = 3*nu + 0.5
nu  = (tau - 0.5) / 3
```

要求 `nu > 0`，因此 `tau > 0.5`。solver 构造时就按 `nu` 算出 `tau`，
不要让用户直接传 `tau`——两套参数并存迟早会不一致。

`Lambda` 只在 TRT 时起作用，v1 接受但忽略。以后接 TRT 时用：

```
Lambda = (tau_plus - 0.5) * (tau_minus - 0.5)
tau_plus = tau    (由 nu 得到)
tau_minus = 0.5 + Lambda / (tau - 0.5)
```

## D2Q9 方向表

这张表是整个程序的地基，写死、不许改。`i` 是张量第一维的下标，
`cx` 对应 tensor 的 axis 0（`Nx`），`cy` 对应 axis 1（`Ny`）。

| i | cx | cy | w | opp |
|---|---|---|---|---|
| 0 | 0 | 0 | 4/9 | 0 |
| 1 | 1 | 0 | 1/9 | 3 |
| 2 | 0 | -1 | 1/9 | 4 |
| 3 | -1 | 0 | 1/9 | 1 |
| 4 | 0 | 1 | 1/9 | 2 |
| 5 | 1 | 1 | 1/36 | 7 |
| 6 | 1 | -1 | 1/36 | 8 |
| 7 | -1 | -1 | 1/36 | 5 |
| 8 | -1 | 1 | 1/36 | 6 |

自检（单测里必须写）：`c[i] = -c[opp[i]]`、`sum(w) = 1`、`sum(w*c) = 0`、
`sum(w*c_a*c_b) = cs^2 * delta_ab`、`c[i] == -c[i]` 仅在 `i == 0` 时成立。

## 平衡态

```
cu   = cx*ux + cy*uy
usq  = ux^2 + uy^2
feq  = w * rho * (1 + 3*cu + 4.5*cu^2 - 1.5*usq)
```

二阶矩自检：`sum(feq) = rho`、`sum(feq*c) = rho*u`、
`sum(feq*c_a*c_b) = rho*cs^2*delta_ab + rho*u_a*u_b`。

## 宏观量（含 Guo 力修正）

设 `F` 是体积力密度（每单位体积的力，格子单位），默认全零。

```
rho = sum_i f_i
u   = ( sum_i f_i * c_i + F/2 ) / rho
```

这个 `u` 是**唯一**的宏观速度定义：`feq` 用它，forcing 用它，诊断也用它。
不要在一个地方用 `sum(f*c)/rho`、另一个地方用带上 `F/2` 的版本——
那样稳态会有一个 `O(F*tau)` 的系统偏差，Poiseuille 的误差分析就废了。

固体节点不参与求和，也不参与任何统计。实现上可以整体求和再用 mask 排除，
也可以只在流体节点上算；v1 用"整体算 + mask 掉"，更简单。

## 碰撞：BGK + Guo forcing

```
f_post_i = f_i - (1/tau) * (f_i - feq_i(rho, u)) + S_i
```

其中源项（`cs^2 = 1/3`，所以 `1/cs^2 = 3`、`1/cs^4 = 9`）：

```
S_i = w_i * (1 - 1/(2*tau)) * ( 3*(cx_i - ux) + 9*(cu) * cx_i ) * Fx
                           + ( 3*(cy_i - uy) + 9*(cu) * cy_i ) * Fy
    （两项要合起来写：括号里是向量 (c_i - u)/cs^2 + (c_i·u)/cs^4 * c_i 与 F 的点积）
```

写成向量形式更清楚：

```
S_i = w_i * (1 - 1/(2*tau)) * [ (c_i - u)/cs2 + (c_i·u)/cs4 * c_i ] · F
```

`F = 0` 时整个源项消失，退化为纯 BGK。这条路径要在 `F is None` 时跳过，
不要每步都算一遍再乘零。

注意 `(1 - 1/(2*tau))` 这个因子：漏掉它，程序照样能跑、照样稳定，
但稳态速度会偏低，而且误差随 `tau` 变化。这是最容易被忽略的一处。

## Pull streaming 与半程反弹

时间推进写成 pull 形式：

```
f_new_i(x) = f_post_i(x - c_i)            # 源点是流体
f_new_i(x) = f_post_opp_i(x)              # 源点是固体 → 反射
```

`x` 必须是流体节点；固体节点上的 pdf 不更新，保持初值（一般填 0），
反正永远不会被读到。

物理含义：碰撞在流体节点上做，分布函数向固体"拉"的时候被弹回来。
壁面位置落在流体节点和固体节点正中间，所以叫 half-way，无滑移条件
作用在 `y = 0.5` 或 `y = Ny - 1.5` 这类半整数坐标上。

如果固体在运动（v1 不支持，但记一笔），反射项要加
`2 * w_i * rho_w * (c_i · u_w) / cs^2`，符号取指向壁面的那个方向。

固体节点**不参与碰撞**。具体实现上可以整体做碰撞再 mask，也可以先算
再只写流体节点。v1 推荐"整体算 + 只写流体节点"，因为 Python 层分支比
多余计算更贵。

## 边界条件的处置方式

v1：**x、y 都按周期处理**。也就是所有方向的移位都环绕。

要模拟壁面，就在域内放固体行，比如 Poiseuille 用 `solid[:, 0]` 和
`solid[:, -1]`。周期环绕本身不会造成问题，因为这两行是固体：
流体节点向它们 pull 的时候走的是反射分支，根本不会绕到对面去。

这么定的好处是不需要"边界行必须是固体"这种隐含假设，也不会出现
流体节点绕一圈跑到对面、却因为边界非周期而越界的情况。

代价是：如果哪天想做真正的壁面边界（非周期），得改 streaming 的移位逻辑。
记在这里，别到时候翻代码才想起来。

Zou/He 入口出口（`x=0` 速度入口、`x=Nx-1` 压强出口）**只留位置**：
在 `D2Q9Solver` 里留一个 `_apply_open_boundary()` 的空方法，`_step_once`
末尾调用它，里面什么都不做。不做通用边界框架，不做注册机制。
等真要写的时候，直接在 D2Q9 里加三层 `if` 都比抽象划算。

## 有效壁面与 Poiseuille 解析解

几何：`solid[:, 0] = solid[:, -1] = True`，流动沿 x，周期。

流体节点在 `y = 1 .. Ny-2`，共 `H = Ny - 2` 行。
半程反弹的有效壁面在 `y = 0.5` 和 `y = Ny - 1.5`。

稳态 NS 方程（x 周期 → 无压力梯度，只剩体积力）：

```
rho * nu * d2u/dy2 + Fx = 0
```

解得：

```
ux(y) = Fx / (2 * nu) * (y - 0.5) * (Ny - 1.5 - y)      (取 rho = 1)
```

峰值在中线 `y = Ny/2 - 0.5`（Ny 为偶数时落在半格点上，网格上没有这个点，
这没关系，比较时插值或者直接逐点比）：

```
ux_max = Fx * H^2 / (8 * nu)
```

`uy` 在整个域内理论上严格为 0（对称性），可以当作一个非常灵敏的检查项。

注意：解析解里的 `y` 是**有效壁面坐标**，不是节点索引。直接把节点索引
代进去会有一个 `O(dx)` 的系统偏移，误差曲线会离谱。这是这类验证里最常见
的翻车点。

## 稳定性约束

- 马赫数：`Ma = u_max / cs < 0.1` 比较安全，超过 0.3 基本不能信
- 松弛时间：`tau` 不能太接近 0.5，`nu < 0.01` 时要小心
- `tau` 太大（>`2`）会让边界层的数值误差变明显

选参数时先算 `ux_max = F*H^2/(8*nu)`，确认 `Ma = ux_max*sqrt(3) < 0.1`，
再确定跑多少步：粘性扩散时间大约 `H^2/nu`，稳态至少跑 5~10 倍这个量。
