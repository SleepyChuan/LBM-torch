# 验证方案

验证分四层，从便宜到贵。前两层是单测，后两层是算例。
**每一层不过，就不要看下一层的结果。**

## 第一层：代数的自洽性

只检查公式本身，不涉及时间推进。

方向表：`c[i] = -c[opp[i]]`、`sum(w) = 1`、`sum(w*c) = 0`、
`sum(w*c_a*c_b) = cs^2 * delta_ab`。

平衡态：对随机 `rho, u` 检查
`sum(feq) = rho`、`sum(feq*c) = rho*u`、
`sum(feq*c_a*c_b) = rho*cs^2*delta_ab + rho*u_a*u_b`，
以及 `feq_i(u) = feq_opp_i(-u)`。

这些用 fp32 做，容差 `1e-5`。如果这里就要放到 `1e-3` 才过，
说明公式里的系数写错了（最常见是把 `4.5` 写成 `3`，或者 `1.5` 写成 `1`）。

## 第二层：时间推进的结构不变量

### 均匀平衡态不动点

无固体、全周期、`rho=1, u=(0.02,0)` 的均匀场。这个场是精确解，
跑多少步都应该纹丝不动。

容差 `1e-6`（fp32 累加 1000 步的舍入量级）。跑 1000 步。

这一条不过，后面所有结果都没有意义。

### 静止流体加固体

`rho=1, u=0` 加任意固体块。因为 `u=0` 时 `feq_i = feq_opp_i`，
反射分支和正常分支给出相同的值，所以整场仍然是精确解。

容差同上。另外检查总质量守恒 `1e-7`。

### 碰撞的不动点与守恒

`feq` 输入碰撞算子是恒等映射；任意输入碰撞后 `rho`、`rho*u` 不变。

### 均匀力驱动的动量增长

全域周期、无固体、`u0 = 0`、`F = (F_x, 0)`。跑 n 步之后期望

```
u_x = (n + 0.5) * F_x
```

那个 `0.5` 不是笔误：动量 `M = sum(f*c)` 每步增加 `F`，而宏观速度定义是
`u = (M + F/2)/rho`，所以 `u` 比 `n*F` 多出半个 `F`。写成 `n*F` 会留下
一个 `1/(2n)` 的相对偏差，n=100 时是 5e-3，足以把这条测试变成"永远差一点"。

**容差要用绝对量级**：`|u_x - expected| < 1e-6`。因为动量是 `sum(f*c)` 的
抵消结果，float32 下绝对误差固定在 1e-7 量级、与步数无关；用相对容差在
小速度上会失真。

单步（n=1）时 `u = 1.5F`，噪声极小，可以卡到 `1e-7` 绝对误差。
这条专门盯 `F/2` 和 `(1 - 1/(2*tau))` 两个因子——漏了 `F/2`，n=1 时
u 会差 1/3；漏了 `(1 - 1/(2*tau))`，偏差随 `tau` 变，把 `tau` 从 0.8
改成 1.5 再跑一遍就能看出来。

注意 `u=0` 时 `sum(S_i) = 0`，所以密度在纯力驱动下是严格守恒的，
可以用 `rho_min == rho_max == 1` 再卡一道。

## 第三层：Poiseuille 剖面

### 几何与参数

```
model  = D2Q9
shape  = (4, 16)          # Nx=4 足够，因为 x 方向均匀
solid[ :, 0] = True
solid[ :, -1] = True
nu     = 0.1              # tau = 0.8
F      = (1e-4, 0)
rho0   = 1.0
u0     = (0, 0)
steps  = 20000            # 约 10 个粘性时间 H^2/nu = 1960
compute_dtype = float32
output_dtype  = float32   # 做误差分析时不要用 float16
```

预期峰值：

```
H = Ny - 2 = 14
ux_max = F * H^2 / (8*nu) = 1e-4 * 196 / 0.8 = 2.45e-2
Ma = ux_max * sqrt(3) ≈ 0.042
```

### 解析解

```
ux(y) = F/(2*nu) * (y - 0.5) * (Ny - 1.5 - y)
```

`y` 取 1 到 Ny-2。注意这是**有效壁面坐标**，`0.5` 和 `Ny-1.5` 是半程反弹
壁面所在的位置，不是节点索引。直接把索引代进 `y` 会引入半个格子的偏移，
在 `Ny=16` 这种小网格上误差会到 10% 量级，还以为是代码写错了。

### 判据

| 检查项 | 容差 | 说明 |
|---|---|---|
| `max\|uy\|` | `< 1e-5` | 对称性，理论上严格为 0 |
| `ux` 剖面对比解析解，相对 L2 | `< 3%` | 只统计 `y ∈ [2, Ny-3]` 的内部行 |
| 总质量漂移 | `< 1e-4` 相对 | x 周期、壁面无穿透，应严格守恒（见下方注） |
| NaN / Inf | 无 | |
| 稳态判据 | `\|du_max/dt\| / u_max < 1e-6` 每步 | 用于确定该跑多少步 |

内部行排除最靠墙的 2 行，是因为半程反弹在壁面附近本身有 `O(dx^2)` 的
滑移误差，而且 `Ny=16` 时壁面影响会渗进 3~4 行。这不是程序错了。

如果非要把全断面都算进去，那就得用更高分辨率，或者改用插值反弹（Bouzidi），
那是后面的事。

**关于质量容差**：解析上质量应该严格守恒（碰撞守恒、streaming 守恒、壁面
"丢弃的"和"反射回来的"正好抵消）。float32 下会有一个**饱和**的舍入平台，
不再随步数增长：

| 碰撞 | float32 相对漂移 | float64 |
|---|---|---|
| BGK | 3.5e-6 | 1e-11 |
| TRT | 2.3e-5 | 1e-11 ~ 1e-10 |

TRT 的碰撞多几步运算，平台高一个量级。所以判据用 `1e-4` 相对：
真正的质量泄漏会随步数线性增长，和这个饱和平台很容易区分。
用 float32 时把阈值卡在 `1e-5` 会误报。

### 关于"入口效应"

x 方向是周期的、流动是充分发展的，**不存在入口**。所以不需要特意在靠近
`x=0` 的地方取截面——沿 x 任一列的结果都相同（到舍入误差）。可以在测试里
顺便验证这一点：取 `x=1` 和 `x=Nx-2` 两列，剖面差异应 `< 1e-6`。

如果哪天改成 Zou/He 入口出口，入口效应才成立，那时候才需要在 `x` 靠近入口
的位置取截面，而且要离入口至少 5~10 个格子。

## 第四层：网格收敛

**固定马赫数，不要固定体积力。**这是这一步唯一需要注意的事。

固定 `F` 时 `u_max = F*H^2/(8*nu) ∝ H^2`，加密网格等于加大马赫数。
`Ny=64` 时 `u_max ≈ 0.39`、`Ma ≈ 0.68`，测到的已经不是离散误差而是
压缩性误差，误差不降反升，很容易被误判成"代码有问题"。

所以改成固定目标速度，反过来算力：

```
u_max_target = 0.02
F = 8 * nu * u_max_target / H^2
```

取 `nu = 0.1`、`Ny ∈ {16, 32, 64}`：

| Ny | H | F | 步数 ≈ 8*H^2/nu |
|---|---|---|---|
| 16 | 14 | 8.16e-5 | 20000 |
| 32 | 30 | 1.78e-5 | 80000 |
| 64 | 62 | 4.16e-6 | 320000 |

（`F = 8*nu*u_max/H^2`，代入 `nu=0.1, u_max=0.02` 得 `F = 0.016/H^2`。）

三档的 `Ma` 都约 0.035，比较的才是纯粹的离散误差。

计算内部区域的相对 L2 误差，期望每加密一倍误差降到 1/4 左右。
在 32 → 64 上观测阶不低于 1.8 就算合格；严格 2.0 不建议写成硬断言，
小网格上的壁面误差会让前两档的阶偏低。

这一步很慢，标 `slow`，在 CI 里可以只在 `main` 上跑。

## 结果记录

每次跑完把这几项写进 `examples/` 下的一个 markdown 或直接打印：

```
Ny, u_max_numeric, u_max_analytic, rel_L2, max|uy|, mass_drift, steps
```

后面改碰撞模型（BGK → TRT）时，拿同样的表对比，才知道改动是变好了还是变坏了。

### 当前实测（D2Q9, TRT Λ=3/16, float32, 已通过）

第三层算例（`Nx=4, Ny=16, nu=0.1, F=1e-4, 20000 步`）。BGK 的旧数据一起列出来，
方便对比 TRT 的收益：

| 项 | TRT (cpu / mps) | BGK (cpu / mps) | 判据 |
|---|---|---|---|
| `u_max` 数值 | 2.437482e-2 / 2.437488e-2 | 2.430899e-2 / 2.430738e-2 | 解析 2.437500e-2 |
| 内部相对 L2 | 0.0008% / 0.0005% | 0.3545% / 0.3603% | < 1% |
| `max\|uy\|` | 6.3e-8 / 7.5e-8 | 4.0e-7 / 6.2e-8 | < 1e-5 |
| 质量漂移（相对） | 2.3e-5 / 1.9e-6 | 3.5e-6 / 8.2e-7 | < 1e-4 |
| `Ma` | 0.042 | 0.042 | < 0.1 |

**TRT 比 BGK 好了四个数量级，原因不是粘度。** $\Lambda=3/16$ 让半程反弹的
**有效壁面位置与 $\tau$ 无关**，正好落在 `0.5` 这个半格点上；BGK 的壁面位置
有 $O((\tau-0.5)^2)$ 的偏移，`Ny=16`、$\tau=0.8$ 时表现为 0.35% 的系统误差。

所以之前"0.35% 已经不错、是壁面附近 $O(dx^2)$ 误差"的判断是错的方向——
那不是离散误差，是壁面位置误差，换成 TRT 就消失了。这也意味着
**`u_max` 那条判据可以把阈值收紧到 1%**，现在留了三个数量级的余量。

cpu 与 mps 的 `ux` 最大差异 1.6e-6，说明两个后端在 float32 下行为一致。

`examples/poiseuille.py` 默认算例（`Ny=64, 20000 步`，未完全收敛）：
TRT `rel_L2 = 0.528%`，BGK `0.660%`。

第四层（固定 `u_max=0.02`）：`Ny=16` 与 `Ny=32` 均已跑通且 `rel_L2 < 3%`；
观测阶在 `docs` 里没有写成硬断言，需要时手动跑 `Ny=64` 补上。
